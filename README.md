# Proyecto GB RA2026

El juego esta en [`moiGruppaTD/`](moiGruppaTD/README.md). Es un tower defense
para Game Boy escrito en ensamblador LR35902 con RGBDS y el Makefile de GBTelera.

Los directorios `ch05-train/` y `ch06-train/` son ejemplos de clase y se mantienen
separados del juego. No hay que compilar los tres proyectos juntos.

Consulta el [README del juego](moiGruppaTD/README.md) para estructura, controles,
reglas y compilacion, y el [plan de pruebas](moiGruppaTD/docs/PRUEBAS_VM.md)
para comprobarlo en la maquina virtual.
